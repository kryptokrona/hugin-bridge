> A simple bridge between social platforms and Hugin Messenger.

## ✨ Features
- Node.js + Express backend
- Multi-platform support (Discord, Telegram)
- Kryptokrona wallet integration
- Real-time messaging bridge

## 🛠 Tech Stack
- Node
- Express
- kryptokrona-wallet-backend-js
- kryptokrona-crypto
- Discord.js
- Telegram API
